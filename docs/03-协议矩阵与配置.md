# 协议矩阵与配置

本文件汇总每个协议 Provider 的能力、连接方式、配置项与默认操作映射。
所有 Provider 对上层暴露完全一致的 `IMesClient`，切换只需换 `UseXxx(...)` 与配置。

---

## 1. 能力矩阵

| Provider | 包 | 底层 SDK | 请求/响应 | 发布 | 订阅 | 典型场景 |
| --- | --- | --- | :---: | :---: | :---: | --- |
| InMemory | `Mes.Protocols.InMemory` | — | ✓ | ✓ | ✓ | 单元测试、界面演示、离线联调 |
| REST | `Mes.Protocols.Rest` | HttpClient | ✓ | — | — | 现代 MES 的 HTTP/JSON API |
| MQTT | `Mes.Protocols.Mqtt` | MQTTnet | 请求/响应(RPC) | ✓ | ✓ | 物联网/产线消息总线 |
| FileDrop | `Mes.Protocols.FileDrop` | 文件系统 | 读文件 | ✓(落盘) | ✓(监视) | 老旧 MES 的文件交换（CSV/JSON） |
| Database | `Mes.Protocols.Database` | ADO.NET(SQLite/SqlServer) | ✓ | ✓ | — | MES 中间库直连 |
| OPC UA | `Mes.Protocols.OpcUa` | Workstation.UaClient | 读/写/调用 | — | — | 设备/SCADA/部分 MES 的 OPC UA 层 |
| SECS/GEM | `Mes.Protocols.SecsGem` | Secs4Net(HSMS) | ✓ | ✓ | ✓ | 半导体/面板行业设备通信 |
| SOAP/WCF | `Mes.Protocols.Soap` | HttpClient + SOAP 信封 | ✓ | — | — | 传统 MES（SAP ME/MII 等）WebService |
| Kafka | `Mes.Protocols.Kafka` | Confluent.Kafka | 请求/响应(RPC) | ✓ | ✓ | Industry 4.0 / MES 事件流 |
| AMQP | `Mes.Protocols.Amqp` | RabbitMQ.Client | 请求/响应(RPC) | ✓ | ✓ | 企业消息总线 |
| WebSocket | `Mes.Protocols.WebSocket` | ClientWebSocket | 请求/响应(RPC) | ✓ | ✓ | 实时下发/看板推送（含 SignalR 风格网关） |
| gRPC | `Mes.Protocols.Grpc` | Grpc.Net.Client | ✓ | ✓ | ✓ | 新一代内网高性能 RPC |
| **聚合包** | `Mes` | 以上全部 | ✓ | ✓ | ✓ | 一次引入 + 连接字符串/配置自动选协议 |

## 2. 通用配置（`MesOptions`）

```csharp
o.Protocol = MesProtocolKind.Rest;         // 协议
o.Endpoint.BaseAddress = "https://...";     // 或 Host/Port/UseTls
o.Auth.Type = MesAuthType.BearerToken;      // None/Basic/BearerToken/ApiKey/OAuth2ClientCredentials/UsernamePassword/...
o.Auth.Token = "xxx";
o.Retry.MaxAttempts = 3;                     // 重试
o.TimeoutMs = 30_000;                        // 超时
o.Image.MaxEmbeddedBytes = 2 * 1024 * 1024;  // 图像内嵌阈值
o.DefaultHeaders["X-Line"] = "L1";           // 附加头
o.SetProperty("Provider", "Sqlite");         // 协议私有键值（见下）
```

**鉴权类型**：`None` / `Basic` / `BearerToken` / `ApiKey`(`ApiKeyHeader`) /
`OAuth2ClientCredentials` / `UsernamePassword` / `X509`。

## 2.5 极简接入（连接字符串 / 配置 / 自检）

引用**聚合包 `Mes`** 后，无需手工挑选 `UseXxx` 与 `AddXxxProtocol`：

```csharp
using Mes;

// 一行连接字符串直接创建（scheme 决定协议）
await using var client = MesClients.Connect("kafka://broker:9092?prefix=mes");

// 连通性自检（一行验证配置是否正确）
var check = await client.TestConnectionAsync();   // 返回 MesResult（含耗时/错误信息）
bool ok   = await client.PingAsync();             // 布尔便捷版

// DI + 配置文件（零代码切协议）：appsettings.json 的 Mes:ConnectionString
services.AddMes(configuration);
// 或指定协议 + 手工配置：services.AddMes(MesProtocolKind.Rest, o => { ... });
```

**连接字符串 scheme → 协议**：

| scheme | 协议 | 备注 |
| --- | --- | --- |
| `mem` / `inmemory` / `loopback` | InMemory | 测试/演示 |
| `rest` / `http` / `https` | REST | `https` 自动 TLS |
| `mqtt` / `mqtts` / `tcp` | MQTT | `mqtts` 自动 TLS |
| `opc.tcp` / `opcua` / `opc` | OPC UA | |
| `file` / `filedrop` | FileDrop | `file:///path` 或 `file:相对路径` |
| `db` / `sqlite` / `mssql` / `sqlserver` / `sql` | Database | `db:<原生连接串>` 或 URI |
| `secs` / `hsms` / `gem` | SECS/GEM | |
| `soap` / `soaps` / `wcf` | SOAP | `soaps` 自动 TLS |
| `kafka` | Kafka | 主机端口即 `BootstrapServers` |
| `amqp` / `amqps` / `rabbitmq` | AMQP | 路径为 VirtualHost，`amqps` 自动 TLS |
| `ws` / `wss` / `websocket` / `signalr` | WebSocket | `wss` 自动 TLS |
| `grpc` / `grpcs` | gRPC | `grpcs` 自动 TLS |

查询参数：`?token=` → Bearer；`?apikey=&apikeyheader=` → ApiKey；`?username=&password=` 或 `user:pass@host` → 账号密码；
`?tls=true` 强制 TLS；其余键进入 `Properties` 供各 Provider 读取。

**稳健性开关**：

```csharp
o.Reconnect.Enabled = true;          // 断线后自动重连并恢复订阅（默认开）
o.Reconnect.InitialDelayMs = 1000;   // 退避起始
o.Reconnect.MaxDelayMs = 30_000;     // 退避上限
o.Reconnect.MaxAttempts = 0;         // 0 = 无限重试
```

**可观测性**：`Mes.Core.Diagnostics.MesDiagnostics` 暴露 `ActivitySource`/`Meter`（名称均为 `Mes.Client`）。
接 OpenTelemetry 时 `AddSource("Mes.Client")` + `AddMeter("Mes.Client")` 即可采集调用追踪、次数与耗时。

## 3. 各 Provider 详解

### 3.1 InMemory（进程内回环）
```csharp
var server = new InMemoryMesServer();            // 可预置数据/自定义处理
server.WorkOrders["WO-1001"] = new WorkOrder { Id = "WO-1001" };
var client = MesClientBuilder.Create().UseInMemory(server).Build();
```
- 无网络，进程内直接回应。`OnRequest(key, handler)` 自定义响应；`PushAsync(channel, payload)` 模拟下发；
  `Reported*` / `Uploaded*` 队列断言收到的数据 —— 非常适合测试与 WPF 演示。

### 3.2 REST（HTTP / JSON）
```csharp
var client = MesClientBuilder.Create()
    .UseRest("https://mes.factory.com")
    .WithAuth(a => { a.Type = MesAuthType.BearerToken; a.Token = "..."; })
    .Build();
```
- 默认映射（可 `MapOperation` 覆盖）：

| 操作 | 方法 | 路径模板 |
| --- | --- | --- |
| GetWorkOrder | GET | `/api/mes/workorders/{workOrderId:url}` |
| GetUnit | GET | `/api/mes/units/{serialNumber:url}` |
| CheckUnitPassed | GET | `/api/mes/units/{serialNumber:url}/gate/{operationId:url}` |
| ReportInspection | POST | `/api/mes/inspections` |
| ReportMeasurements | POST | `/api/mes/units/{serialNumber:url}/measurements` |
| UploadImage | POST | `/api/mes/images` |
| ReportDeviceStatus | POST | `/api/mes/devices/{deviceId:url}/status` |
| RaiseAlarm | POST | `/api/mes/alarms` |
| ClearAlarm | POST | `/api/mes/alarms/{alarmCode:url}/clear` |
| GetRecipe / GetTraceability | GET | `/api/mes/recipes/{recipeId:url}` / `/api/mes/traceability/{serialNumber:url}` |

### 3.3 MQTT
```csharp
var client = MesClientBuilder.Create()
    .UseMqtt("broker.factory.com", 1883)
    .WithAuth(a => { a.Type = MesAuthType.UsernamePassword; a.Username = "u"; a.Password = "<从安全配置读取>"; })
    .Build();
```
- 私有属性：`TopicPrefix`（默认 `mes`）、`ClientId`（默认自动生成）。
- 上报走**发布**到 `TopicPrefix/...`；查询走**请求/响应**（发到请求主题、等回复主题）；`SubscribeAsync` 订阅主题。

### 3.4 FileDrop（文件落地交换）
```csharp
var client = MesClientBuilder.Create()
    .UseFileDrop(@"\\fileserver\mes-exchange")
    .Build();
```
- 上报把 JSON 写到 `根目录/outbox/<类别>/*.json`（原子写：先 `.tmp` 再改名）。
- 私有属性：`ProcessedFolder`（默认 `.processed`，回读后归档）。
- 订阅用 `FileSystemWatcher` 监视 inbox；查询读取指定文件。

### 3.5 Database（数据库直连）
```csharp
var client = MesClientBuilder.Create()
    .UseDatabase("Data Source=mes.db", provider: "Sqlite",
                 configure: o => o.SetProperty("EnsureSchema", "true"))
    .Build();
```
- 私有属性：`Provider`（`Sqlite` / `SqlServer`）、`EnsureSchema`（`true` 时自动建 `mes_*` 示例表）。
- 通道模板即 **SQL 文本**，命名参数 `@name` 来自 `args` 与内置 `@json`(载荷) / `@now`。
  查询动词（GET/SELECT/QUERY/READ）走 `ExecuteReader`，其余走 `ExecuteNonQuery` 返回 `{"affected":n}`。
- 依赖：`Microsoft.Data.Sqlite` / `Microsoft.Data.SqlClient`（**非**过时的 System.Data.SqlClient）。

### 3.6 OPC UA
```csharp
var client = MesClientBuilder.Create()
    .UseOpcUa("opc.tcp://server:4840")
    .WithAuth(a => { a.Type = MesAuthType.UsernamePassword; a.Username = "u"; a.Password = "<从安全配置读取>"; })
    .Build();
```
- 通道 = **NodeId**（如 `ns=2;s=Line1.WorkOrder`），动词 ∈ `read` / `write` / `call`。
- 私有属性：`SecurityPolicy`（默认 None）。调用方法用 `"对象NodeId|方法NodeId"`。
- 依赖：`Workstation.UaClient`。默认映射为占位 NodeId，**必须**按现场地址空间用 `MapOperation` 覆盖。

### 3.7 SECS/GEM（HSMS）
```csharp
var client = MesClientBuilder.Create()
    .UseSecsGem("192.168.0.10", 5000,
                configure: o => { o.SetProperty("Mode", "Active"); o.SetProperty("DeviceId", "0"); })
    .Build();
```
- 通道 = `S{stream}F{function}`（如 `S1F3`、`S6F11`）。请求体转 `Item.A(json)`。
- 私有属性：`Mode`(Active/Passive)、`DeviceId`、`T3/T5/T6/T7/T8`、`LinkTestInterval`、`ConnectTimeoutMs`、`AutoReplyPrimary`。
- 订阅：后台接收一次消息（primary），按 `SxFy` 分发并可自动回空 secondary。
- 依赖：`Secs4Net`。默认映射为占位 `SxFy`，**必须**按设备的 SECS 字典用 `MapOperation` 覆盖。

### 3.8 SOAP / WCF
```csharp
var client = MesClientBuilder.Create()
    .UseSoap("https://mes.factory.com/MesService.asmx", serviceNamespace: "http://mes.local/")
    .WithAuth(a => { a.Type = MesAuthType.BearerToken; a.Token = "..."; })
    .Build();
```
- 面向“JSON-over-SOAP”约定：请求体（JSON）作为操作元素文本发送，响应从 `soap:Body` 首个子元素取回内层文本/JSON。
- 私有属性：`Namespace`（服务命名空间，默认 `http://mes.local/`）、`SoapVersion`（`1.1` 默认 / `1.2`）。
- 通道 = 操作名（如 `GetWorkOrder`）；SOAP 1.1 走 `SOAPAction` 头，SOAP 1.2 走 `action` 参数。

### 3.9 Kafka
```csharp
var client = MesClientBuilder.Create()
    .UseKafka("broker1:9092,broker2:9092", configure: o => o.SetProperty("TopicPrefix", "mes"))
    .Build();
```
- 上报走**发布**到 `prefix.xxx` 主题；查询走 **RPC**（回复主题 + `correlationId` 关联头）。
- 私有属性：`BootstrapServers`（或从连接字符串主机端口推导）、`TopicPrefix`、`GroupId`、`ReplyTopic`。
- 依赖：`Confluent.Kafka`。

### 3.10 AMQP（RabbitMQ）
```csharp
var client = MesClientBuilder.Create()
    .UseAmqp("rabbit.factory.com", 5672,
             configure: o => { o.SetProperty("VirtualHost", "/prod"); o.SetProperty("Exchange", "mes"); })
    .Build();
```
- 上报**发布**到主题交换机（routing key = `prefix.xxx`）；查询走 **RPC**（回复队列 + `correlationId`）。
- 私有属性：`VirtualHost`、`Exchange`（默认 `mes`，topic 类型）、`TopicPrefix`。
- 依赖：`RabbitMQ.Client`（7.x 全异步 API）。

### 3.11 WebSocket / SignalR
```csharp
var client = MesClientBuilder.Create()
    .UseWebSocket("wss://mes.factory.com/ws")
    .WithAuth(a => { a.Type = MesAuthType.BearerToken; a.Token = "..."; })
    .Build();
```
- 单条长连接 + 统一 JSON 信封（`type`/`channel`/`correlationId`/`success`/`error`/`body`）承载请求/响应与发布/订阅。
- 私有属性：`SubProtocol`（可选，用于 SignalR 风格子协议）。约定兼容自定义 WebSocket 网关与 SignalR 消息路由。

### 3.12 gRPC
```csharp
var client = MesClientBuilder.Create()
    .UseGrpc("https://mes.factory.com:5001")
    .WithAuth(a => { a.Type = MesAuthType.BearerToken; a.Token = "..."; })
    .Build();
```
- 经由通用 `MesGateway` 契约（`Invoke` 一元 / `Publish` 一元 / `Subscribe` 服务端流）承载所有操作，通道即逻辑方法名。
- 鉴权通过 gRPC `Metadata`（Bearer/ApiKey）注入；`grpcs`/https 端点自动启用 TLS。
- 依赖：`Grpc.Net.Client` + `Google.Protobuf`（`.proto` 见 `src/Mes.Protocols.Grpc/Protos`）。

## 4. 覆盖默认映射

任何工厂的“非标接口”都可通过覆盖操作映射适配，业务代码不变：

```csharp
var client = MesClientBuilder.Create()
    .UseRest("https://mes...")
    .MapOperation("GetWorkOrder", "/erp/v2/wo/{workOrderId}", "GET")   // 换 URL
    .MapOperation("ReportInspection", "/erp/v2/inspect", "POST")
    .Build();
```

或对完全私有的接口用通用出口：
```csharp
var r = await client.InvokeAsync<MyDto>("MyCustomOp",
            payload: myRequest,
            args: new Dictionary<string, object?> { ["id"] = "X" });
```
