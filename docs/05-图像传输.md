# 图像传输

> 机器视觉检测软件产生大量图像，需要连同检测结果一起回传给 MES。本库把图像抽象为
> `MesImage`，并支持**内嵌**、**单独上传**、**仅引用**三种传输模式，逐张图像可独立选择，
> 且在内嵌超阈值时**自动切换**为单独上传。总纲见 [开发指导文档](./01-开发指导文档.md)。

---

## 1. `MesImage` 模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Id` | `string` | 图像唯一标识（默认 GUID），供缺陷/结果引用。 |
| `FileName` | `string?` | 文件名（含扩展名），用于推断格式。 |
| `Format` | `ImageFormat` | 图像格式（`Png`/`Jpeg`/`Bmp`/`Tiff`/`Webp`/`Unknown`）。 |
| `ContentType` | `string?` | MIME 类型（如 `image/png`）。 |
| `TransferMode` | `ImageTransferMode` | 传输模式，默认 `SeparateUpload`。 |
| `Data` | `byte[]?` | 图像字节（内嵌必填；单独上传可从磁盘读取）。 |
| `LocalPath` | `string?` | 本地路径；框架据此读取字节。 |
| `RemoteUri` | `string?` | 远端引用（仅引用必填；单独上传后回填）。 |
| `StorageKey` | `string?` | 对象存储 key（单独上传后回填）。 |
| `Width` / `Height` | `int?` | 像素尺寸。 |
| `Sha256` | `string?` | SHA-256 十六进制（可选，用于去重/完整性校验）。 |
| `Length` | `long?` | 字节大小（只读，来自 `Data`）。 |

辅助方法：

```csharp
// 依据文件名推断格式与内容类型
(ImageFormat Format, string ContentType) MesImage.InferFormat(string? fileName);

// 从本地文件创建图像（默认单独上传模式）
MesImage MesImage.FromFile(string path, ImageTransferMode mode = ImageTransferMode.SeparateUpload);
```

---

## 2. 三种传输模式

`ImageTransferMode`：

| 模式 | 含义 | 适用场景 |
| --- | --- | --- |
| `Embedded` | 图像字节随检测结果一起提交（Base64 内嵌）。 | 小图、要求单次事务提交。 |
| `SeparateUpload` | 先调用上传接口把图像单独传走，拿到引用（URI/Key）后，结果里只带引用。 | 大图、对象存储、带宽敏感。 |
| `ReferenceOnly` | 图像已存在于外部存储，结果里只带 URI（库不再上传）。 | 图像由外部系统托管。 |

可对**同一批**图像逐张设置不同模式，满足“有些内嵌、有些单独上传”的需求。

---

## 3. 图像处理流程

在 `ReportInspectionResultAsync` 内部，`result.Images` 中的每张图像都会经过：

1. **准备（`PrepareImageAsync`）**
   - 若 `Data` 为空且 `LocalPath` 存在，则从磁盘读取字节；
   - 若 `Format == Unknown` 且有 `FileName`，则按扩展名推断 `Format` 与 `ContentType`；
   - 若 `MesImageOptions.ComputeSha256` 为真且尚无 `Sha256`，则计算 SHA-256（小写十六进制）。
2. **解析模式（`ResolveTransferMode`）**
   - 若模式为 `Embedded` 且 `MaxEmbeddedBytes > 0` 且图像字节数**超过阈值**，
     则自动改为 `SeparateUpload`（避免超大报文）。
3. **执行**
   - `SeparateUpload`：先走上传通道 `UploadImageAsync`；成功后**清空 `Data`** 并把该图像标记为
     `ReferenceOnly`，从而避免随结果重复传输；
   - `Embedded`：字节随结果一同提交，不走上传通道。

> 单独调用 `UploadImageAsync(image)` 时，同样会先执行“准备”步骤，然后按上传操作的绑定语义处理：
> 请求/响应协议（如 REST）返回真实回执并回填 `RemoteUri`/`StorageKey`；发布语义协议（如 MQTT）
> 无回执，返回合成回执。

---

## 4. 配置：`MesImageOptions`

通过 `builder.WithImageOptions(o => ...)` 或 `options.Image` 配置：

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `DefaultTransferMode` | `SeparateUpload` | 默认传输模式（可被单张图像覆盖）。 |
| `UploadOperationKey` | `UploadImage` | 单独上传所用的操作键。 |
| `MaxEmbeddedBytes` | `2 * 1024 * 1024`（2 MB） | 内嵌上限；超过自动改为单独上传。`0` 表示不限制。 |
| `ComputeSha256` | `true` | 传输前是否计算 SHA-256。 |

## 5. 示例

### 5.1 内嵌小图

```csharp
var inspection = new InspectionResult
{
    SerialNumber = "SN-0001",
    Outcome = InspectionOutcome.Pass,
    Images =
    {
        new MesImage
        {
            FileName = "front.png",
            TransferMode = ImageTransferMode.Embedded,
            Data = File.ReadAllBytes(@"C:\imgs\front.png")
        }
    }
};

await client.ReportInspectionResultAsync(inspection);
```

### 5.2 大图单独上传（结果只带引用）

```csharp
var inspection = new InspectionResult
{
    SerialNumber = "SN-0002",
    Outcome = InspectionOutcome.Fail,
    Images =
    {
        MesImage.FromFile(@"C:\imgs\defect.tiff", ImageTransferMode.SeparateUpload)
    }
};

// 框架先上传该图像，回填 RemoteUri，再上报只带引用的结果
await client.ReportInspectionResultAsync(inspection);
```

### 5.3 超阈值自动切换

```csharp
var client = MesClientBuilder.Create()
    .UseRest("https://mes.factory-a.com")
    .WithImageOptions(o => o.MaxEmbeddedBytes = 512 * 1024) // 512KB 以上自动改走单独上传
    .Build();
```

上述行为均由单元测试 `ImageTransferTests` 覆盖（内嵌、单独上传、上传回执、超阈值自动切换），
详见 [测试与 WPF 界面](./06-测试与WPF界面.md)。
